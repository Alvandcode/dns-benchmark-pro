DNS Benchmark Pro • نسخه 1.4.0

🎓 آموزش قدم‌به‌قدم: سریع‌ترین DNS را خودت پیدا کن

بدون حدس و شنیده‌ها — با عدد و نمودار. یکی از دو مسیر زیر را انتخاب کن:

۱ نصب ترموکس (فقط اندروید)

از F-Droid برنامه Termux را نصب کن (نسخه گوگل‌پلی قدیمی است). بعد این دستورها را یکی‌یکی بزن:

pkg update && pkg install python git -y
git clone https://github.com/Alvandcode/dns-benchmark-pro
cd dns-benchmark-pro
pip install requests matplotlib
اگر نصب matplotlib طول کشید یا خطا داد اشکالی ندارد — ابزار بدون آن هم کامل کار می‌کند، فقط نمودار ساخته نمی‌شود.

۲ اولین تست ۳۰ ثانیه‌ای

python main.py --queries 5 --seed 42

اگر جدول امتیازها را دیدی، یعنی همه‌چیز درست نصب شده. 🎉

۳ تست مخصوص ایران 🇮🇷

python main.py --preset ir --queries 10 --seed 42

به ستون hijack دقت کن:

✅ cleanمسیر سالم است، به عددها اعتماد کن
🚨 HIJACKEDاینترنتت UDP را دستکاری می‌کند! دستور زیر را بزن:
python main.py --preset ir --queries 10 --protocol doh --seed 42

۴ اعمال نتیجه روی گوشی

هر کدام امتیاز بالاتر و ± کوچک‌تر داشت، همان DNS توست. آن را در تنظیمات وای‌فای گوشی (گزینه DNS خصوصی / Private DNS) وارد کن و تمام!

⚠️ کاربران آیفون: روی iOS ترموکس وجود ندارد. با برنامه a-Shell فقط حالت DoH جواب می‌دهد (--protocol doh). اگر نشد، با کامپیوتر تست بگیر و فقط نتیجه را روی گوشی اعمال کن.

۱ نصب پایتون (فقط بار اول)

🪟 ویندوزاز python.org نسخه 3.9+ — تیک Add to PATH یادت نره
🐧 لینوکسsudo apt install python3 python3-pip git -y
🍎 مکbrew install python git یا نصب از python.org

۲ دانلود و نصب ابزار

git clone https://github.com/Alvandcode/dns-benchmark-pro
cd dns-benchmark-pro
pip install -r requirements.txt
لینوکس/مک: اگر pip پیدا نشد از pip3 استفاده کن. ویندوز: اگر python کار نکرد، py را امتحان کن.

۳ اجرا — از ساده تا حرفه‌ای

# تست سریع
python main.py --queries 5

# تست کامل مخصوص ایران
python main.py --preset ir --queries 20 --seed 42

# مقایسه مطمئن: 3 بار تکرار با فاصله اطمینان
python main.py --preset ir --queries 20 --runs 3 --seed 42

# مانیتورینگ: هر 5 دقیقه یک تست (بهترین DNS در طول روز)
python main.py --preset ir --queries 10 --watch 300 --seed 42
python main.py --trend

۴ خواندن نتیجه

فایل‌ها در پوشه results ساخته می‌شوند — report.html را در مرورگر باز کن (جدول + نمودار):

به چه چیزی نگاه کنم؟یعنی چه؟
score بالاترDNS بهتر (۰ تا ۱۰۰)
± کوچک‌ترپایدارتر (مثلاً ‎±0.11 عالی، ‎±10 ناپایدار‎)
hijack = HIJACKEDنتیجه UDP را قبول نکن، با DoH دوباره تست بگیر

⚠️ نکته ویندوز: اگر همه TIMEOUT شدند، فایروال یا آنتی‌ویروس پورت UDP/53 را بسته — اول با --protocol doh امتحان کن.
